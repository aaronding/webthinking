    readsooner.com

    ReadSooner

    Save it for later. Get the gist now.

    I was a Pocket user, and I saved more articles than I ever read. When Pocket closed, I built my own read-later app. It hands each article back with a short AI summary first, written in the article’s own language, and I can tell which ones deserve the full read.

    padbench.com

    PadBench

    Is it the controller, or is it me?

    The testers I tried couldn’t check some features of my DualSense, so I built my own. PadBench checks any controller for stick drift, button chatter and polling rate, and goes on to motion, vibration, lights and adaptive triggers.

    rigscope.exe

    Rigscope

    Why did that session run badly?

    A lightweight hardware monitor for Windows gaming PCs. It logs how each game runs, session by session, and explains a bad one: heat, an update or background load.

    gcwind

    How many rings to aim off, answered one-handed.

    A wind calculator for Golf Clash. Pick a club and level, dial in the wind, adjust for power ball, elevation and distance, and it gives you the rings. Built for a thumb on a phone mid-match, with the club data checked in CI on every push.

    scorpion.solitaire

    Scorpion Solitaire

    Written in 2006. Rebuilt in 2026. Every deal can be won.

    I play a lot of solitaire, so I wrote my own in Java Swing. Twenty years later I rebuilt it for the desktop and the browser. A solver shuffles until the deal is winnable, and both versions replay the same rules recording, so a game number deals the same cards in either one.

    maze

    A mouse, a maze and a stack.

    A mouse maps every corridor of a maze using depth-first search, backtracking out of dead ends and noting each exit. The original draws it in your terminal. It began in 2016 as a recursive solver; now it keeps an explicit stack, so every step can be drawn. The one on this page is a browser port, and the code under it is the function that’s running.
